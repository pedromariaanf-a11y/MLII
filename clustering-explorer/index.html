Dataset and problem

Crunchbase startup data, made readable

The analysis starts from a real Crunchbase startup dataset published on Kaggle. The app does not rerun the notebook; it presents the exported clustered profile produced from teste.ipynb.

The main data problem was the number of zeros in funding-source columns. Many startups have no recorded debt, private equity, or early-stage amount, so the model story uses ratios, log features, robust scaling, and medians instead of raw averages.

Project path

The analysis pipeline

This section explains the choices in teste.ipynb before the exported dataset becomes charts and business interpretation.

1

Feature selection

Keep startup descriptors for context, but base the model story on funding scale, rounds, stage, and source mix.

2

Feature engineering

Create source ratios to separate real zeros from dominant funding sources, then use log features to reduce skew.

3

Scale and project

Use RobustScaler so extreme funding rounds do not dominate, then show the results with two PCA components.

4

Explain decisions

Use the exported K-Means labels as fixed outputs, then explain each cluster with medians and readable feature differences.

Data checks

Zeros, missing values, and useful fields

The exported profile is usable, but many funding-source columns are zero. These checks separate zeros from missing values and show which fields are reliable enough to explain.

Feature Glossary

Plain-English meaning of the funding fields used in the final exported dataset.

Funding rounds

How many times the startup officially raised money. More rounds usually suggest more financing activity or a later company journey.

Venture capital

Money from investors who fund startups with high growth potential, usually in exchange for ownership.

Debt financing

Money the company borrows and is expected to repay. It is closer to a loan than selling part of the company.

Private equity

Investment from firms that buy or fund more mature private companies, often with larger capital amounts.

Early-stage funding

Money raised near the beginning of the startup lifecycle, such as seed, angel, or early venture rounds.

Stage level

A simplified maturity score created for the model: lower values mean earlier-stage companies, higher values mean more advanced funding stages.
