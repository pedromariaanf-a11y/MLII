What this page explains

From startup rows to recognizable groups

Clustering is a way to let similar startups gather together based on funding behavior. Instead of predicting an outcome, the method asks: which companies look alike when we compare their funding size, funding rounds, stage, and funding mix?

The original notebook already created cluster labels. This app uses those labels directly, profiles the groups, and translates the technical outputs into readable observations.

Clustering explanation

How the groups were formed

The project notebooks show a K-Means workflow with RobustScaler, PCA for visualization, and four cluster labels. The app uses the exported labels as the source of truth.
