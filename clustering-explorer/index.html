What this page explains

From startup data to useful groups

The project groups startups by funding behavior: how much money they raised, how many rounds they had, their stage, and which funding source dominates.

The app keeps the explanation practical: main clusters first, then a short zoom into Cluster 0 because it contains most of the companies.

Project path

The analysis pipeline

This is the simple path followed in the notebooks before the app turns the results into charts and business interpretation.

1

Clean the data

Keep usable startup rows, remove empty records, and focus on funding and company descriptors.

2

Create funding features

Build totals, rounds, stage level, funding-source amounts, ratios, and log-transformed values.

3

Scale and reduce

Use RobustScaler to reduce outlier impact, then PCA to create compact components for K-Means.

4

Interpret clusters

Use K-Means with four main clusters, then profile each group with real funding values.
